# VolleyCalc

Разметка видео волейбольных матчей и статистика — для тренера и игроков.

- **Тренер** — `coach.html`: разметка, статистика, PDF, пакеты и нарезки для игроков.
- **Игрок** — `player.html`: разбор своей игры, видео своих эпизодов, сезон.
- **Игрок-Junior** — `player.html?v=junior`: простой крупный режим для детей.

Приложение работает целиком в браузере. Матчи, пакеты игроков и видео на сайт не загружаются —
они открываются с устройства и хранятся только в браузере пользователя.
